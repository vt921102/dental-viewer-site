Frequently asked questions

Which files can Dental Viewer open?

Zip exports, case folders, and single files. Meshes in STL, PLY, OBJ, OFF, 3MF, glTF / GLB and VTK; CBCT and DICOM series; and the .3oxz, .dentalproject and .dentalcase containers. Zips inside zips are expanded automatically.

How do I open a case?

Use Import Zip… (⌘O) or Import Folder… (⇧⌘O), drag the zip or folder onto the window, or right-click it in Finder and choose Open With ▸ Dental Viewer.

I opened a single mesh and the case details or snapshots are missing.

For your privacy, macOS only lets the app read exactly what you choose. When you open one file, the other files next to it are off-limits. Import the whole folder or the zip instead and everything in it will appear.

"No 3D meshes or DICOM found in this package."

The export doesn't contain any mesh or DICOM files the app recognises. Check that the zip or folder holds the exported scan files. If it only contains an index.html viewer, open that file in a web browser.

Which systems' case details can it read?

iTero exports show full case information grouped by Patient, Provider and Order. For other systems the meshes, DICOM and snapshots all work, and every metadata field in the bundled XML or JSON is listed as found.

How do I show one part on its own?

Double-click it in the mesh list. Show All Meshes (⇧A) brings the rest back; unchecking a mesh hides it.

Does my data leave my Mac?

No. Dental Viewer has no internet access and never uploads anything. See the Privacy Policy.

Can I use it to diagnose or plan treatment?

No. Dental Viewer is a file viewer. It is not a medical device and is not intended for diagnosis or treatment planning.
